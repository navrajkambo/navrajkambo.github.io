## Tech Stack

- Vanilla HTML, CSS, JavaScript
- Markdown content
- GitHub Pages hosting

## Development

```bash
# Serve locally
python -m http.server 8000 -d

# Hard Refresh
CTRL + F5
```

## Structure

- `/index.html` - Main page
- `/*.md` - Content (about, projects, resume)
- `/styles.css` - Styling
- `/script.js` - Functionality
